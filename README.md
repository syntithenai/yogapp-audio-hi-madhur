# yogapp-audio-hi-madhur

https://syntithenai.github.io/yogapp-audio-hi-madhur/v1/

Published by `apps/yoga/scripts/publish-voice-files.sh` in the yogapp repo.
The phone app downloads the same clips as a zip from
https://syntithenai.github.io/yogapp-audio-hi-madhur/v1/hi-madhur.zip
